# G2 - Escolhedor de Ordenacao

Projeto academico de algoritmos e estruturas de dados.

## Objetivo

Criar um programa que escolha um algoritmo de ordenacao
conforme as caracteristicas da lista e comparar seu desempenho
com os metodos fixos.

## Algoritmos

- Insercao
- Intercalacao (Merge Sort)
- Rapida com pivo aleatorio (Quick Sort)
- Hibrida
- Contagem (Counting Sort)
- Base (Radix Sort)

## Estrutura

- `algoritmos/`: algoritmos e seletor.
- `tests/`: testes do projeto.
- `resultados/`: resultados das medicoes.
- `main.py`: execucao do programa.
- `RELATORIO.md`: analise dos experimentos.
